## 學習目標

1. 正確區分離散分配與連續密度，理解「機率是區間面積」。
2. 使用常態分配、Z 分數與 68–95–99.7 法則。

## 1. 連續型隨機變數與機率密度函數

講義使用身高直方圖逐步增加分箱，說明當把區間切得更細時，可以用平滑曲線來近似分配。對連續型隨機變數 \(X\)，**機率密度函數（probability density function, PDF）** \(f(x)\) 必須滿足：

\[
f(x)\ge0,\qquad\int_{-\infty}^{\infty}f(x)\,dx=1.
\]

\[
P(a\le X\le b)=\int_a^b f(x)\,dx.
\]

即**機率是曲線下的面積，不是曲線的高度**；只問剛好等於某個精確數字時，在連續分配中 \(P(X=x)=0\)。這不表示不可能觀察到某個測量值，而是單一精確值在連續模型裡的面積為零。[S04, PDF p.5] [S04, PDF p.6] [S04, PDF p.7]

**百分位數（percentile）**是分配左側累積達指定比例的數值；25、50、75 百分位數分別對應 \(Q_1\)、中位數、\(Q_3\)。[S04, PDF p.9]

## 2. 常態分配（Normal / Gaussian）

常態分配通常呈對稱、單峰、鐘形。課堂用 \(N(\mu,\sigma^2)\) 表示，\(\mu\) 為平均數、\(\sigma^2\) 為變異數（注意第二個參數不是標準差）。[S04, PDF p.10] [S04, PDF p.12]

**標準化（standardization）**：若 \(X\sim N(\mu,\sigma^2)\)，則

\[
Z=\frac{X-\mu}{\sigma}\sim N(0,1).
\]

\(Z\) 的意思是：觀察值距離均值幾個標準差。大於 0 代表高於平均；小於 0 代表低於平均。[S04, PDF p.12]

### 講義原例：跨考試比較表現

講義以 TOEFL \(N(80,25^2)\)、TOEIC \(N(560,180^2)\) 作例，Judy TOEFL 70 分，Lucy TOEIC 330 分：

\[
Z_{Judy}=\frac{70-80}{25}=-0.4,\qquad Z_{Lucy}=\frac{330-560}{180}\approx-1.28.
\]

兩人都低於各自測驗平均，但 Judy 的相對位置較高。不能直接因為 330 比 70 大，就說 Lucy 在所屬考試族群的排名更好。[S04, PDF p.13] [S04, PDF p.14]

### 常態機率求解

求 \(X\ge c\) 的機率時，先計算 \(z=(c-\mu)/\sigma\)，再找標準常態尾端面積。例如講義的 TOEIC 題：

\[
P(X\ge600)=P\left(Z\ge\frac{600-560}{180}\right)\approx P(Z\ge0.22)=0.4129.
\]

這裡 0.4129 是依講義採 z=0.22 查表的近似值。求不同尾端與左右區間時，可利用對稱性與總面積 1。[S04, PDF p.17] [S04, PDF p.18] [S04, PDF p.20] [S04, PDF p.21]

**68–95–99.7 法則**：常態分配約 68%、95%、99.7% 的觀察值，分別落在均值正負 1、2、3 個 SD 範圍內。這是常態分配的近似性質，不可直接套在任何偏態分布。[S04, PDF p.22]

## 3. 伯努利（Bernoulli）與二項（Binomial）

一個只有成功（1）／失敗（0）兩種結果的試驗，若成功機率是 \(p\)，則 \(X\sim \operatorname{Bernoulli}(p)\)。

\[
E(X)=p,\quad\operatorname{Var}(X)=p(1-p).
\]

若重複進行 **n 次相互獨立、成功率相同**的伯努利試驗，成功次數 \(X\sim\operatorname{Binomial}(n,p)\)：

\[
P(X=x)={n\choose x}p^x(1-p)^{n-x},\quad x=0,1,\dots,n.
\]

\[
{n\choose x}=\frac{n!}{x!(n-x)!},\quad E(X)=np,\quad \operatorname{Var}(X)=np(1-p).
\]

**推導直覺：**特定順序的 x 次成功與 n−x 次失敗機率為 \(p^x(1-p)^{n-x}\)，而成功可擺在 \({n\choose x}\) 種位置，因此相乘。[S04, PDF p.23] [S04, PDF p.25]

**自編例題**：投擲公平硬幣 4 次，恰有 3 次正面之機率

\[
P(X=3)={4\choose3}(0.5)^3(0.5)^1=4/16=0.25.
\]

這是依據 S04 的分配公式自編，非講義原題。[S04, PDF p.25]

## 4. 幾何（Geometric）與負二項（Negative Binomial）

如果問題不是「固定 n 次成功幾次」，而是「**等多久才成功**」，考慮幾何／負二項分配。

- **幾何分配**：\(X\) 是首次成功出現於第幾次試驗，\(P(X=x)=(1-p)^{x-1}p\)，\(E(X)=1/p\)。[S04, PDF p.27]
- **負二項分配（講義的等待時間參數化）**：\(X\) 是第 k 次成功發生於第 x 次試驗，\(P(X=x)={x-1\choose k-1}p^k(1-p)^{x-k}\)，\(x\ge k\)。注意其他教材也可能定義成「成功前的失敗次數」，因此公式所指的 X 需要先確認。[S04, PDF p.29]

**講義原例**：若每胎生女孩的機率 \(p=0.6\)，前四胎男孩、第五胎首位女孩，等同 \(P(X=5)=(0.4)^4(0.6)=0.01536\approx0.0154\)。[S04, PDF p.28]

## 5. 卜瓦松（Poisson）

講義將 \(X\sim\operatorname{Poisson}(\lambda)\) 用於固定時間窗的事件數量，\(\lambda\) 是單位時間平均發生數：

\[
P(X=x)=\frac{\lambda^x e^{-\lambda}}{x!},\quad x=0,1,2,\dots
\]

\[
E(X)=\lambda,\qquad\operatorname{Var}(X)=\lambda.
\]

講義示例為咖啡店平均每小時 50 名顧客，求一小時恰有 60 位顧客的機率；Poisson 模型是簡化假設，實際進店數需檢查事件獨立性與到達率是否大致穩定。講義取 \(P(X=60)\approx0.02\)。[S04, PDF p.30] [S04, PDF p.31]

## 6. 分配怎麼選？

| 問題中的隨機變數 X | 適合的模型 |
|---|---|
| 單次二選一（成功／失敗） | Bernoulli |
| 固定 n 次，成功幾次？ | Binomial |
| 第一次成功發生在第幾次？ | Geometric |
| 第 k 次成功發生在第幾次？ | Negative binomial |
| 一段時間內發生幾件事？ | Poisson |
| 以均值和變異數描述的對稱鐘形連續數據 | Normal（須驗證合適性） |

## 易錯觀念與複習

- PDF 在本章同時可指 **Probability Density Function**，不是 PDF 檔案格式；連續分配的密度值也不是單點機率。[S04, PDF p.5] [S04, PDF p.7]
- \(N(80,25^2)\) 的 SD 是 25，不是 625。[S04, PDF p.13]
- Binomial 要固定試驗次數且試驗獨立、成功機率相同，不能直接套到「抽完不放回」的小母體。[S04, PDF p.25]
- 幾何 X 的定義為「包含成功的總試驗次數」，不是失敗次數。[S04, PDF p.27]

自編複習：一台機器每小時平均 3 次故障，問一小時「恰 2 次」要用哪個模型？若符合固定到達率等假設，**Poisson(3)**，\(P(X=2)=e^{-3}3^2/2!\)。
